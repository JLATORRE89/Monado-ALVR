App updates preserve app data and need an authorized ADB connection. Android checks app signatures and version rules. Standalone APK files are supported.

Quest system firmware

Use an official, unmodified Meta OTA package for your headset. Connect USB while the headset is running normally, then choose Check firmware compatibility. Charge to at least 50%.

After the check, power off the headset, hold Power + Volume Down, and select Sideload update. Refresh this list and select the same headset in sideload mode. Then choose Install stored update. Keep USB connected until recovery finishes. Boot normally and choose Verify installed version.

The panel checks OTA model/build metadata and file integrity. The headset recovery verifies the firmware signature. A matching checksum alone does not establish that a file came from Meta. Packages that wipe data or downgrade firmware are rejected.

Meta’s online software update tool is also available with internet access. It uses WebUSB, so open it in Chrome, Edge or another Chromium browser on a PC (not Firefox or Safari), signed in to meta.com.

Web proxy (optional)

Disabled by default. When enabled, this internet proxy allows only the domains listed for each device. It does not decrypt HTTPS pages or create a device-wide air gap; apps can bypass Android proxy settings. Use network firewall rules for enforced isolation.

Leave forwarding empty for direct access with filtering. Forwarding failures stop requests; there is no direct fallback. Only public internet destinations on ports 80 and 443 are supported.

An empty list blocks every destination. Exact names allow only that host; *.example.com allows its subdomains. Local services should connect directly on your local network.

To use it, set the device’s Wi-Fi proxy to this PC’s LAN address and the proxy port, then enter its assigned login in a proxy-capable browser. This panel does not automatically change device network settings. Keep proxy credentials on your trusted LAN. Turning the proxy off does not block direct internet access.

Panel access

Use this panel from a Quest or supported tablet over Wi-Fi. Connect once by USB and allow this PC's debugging prompt. With automatic authorization enabled below, the device pairs without a separate pairing step.

One setting covers Quest headsets and the Galaxy Tab A9+ (SM-X210). With Wi-Fi access on, its browser opens the pairing page automatically after USB authorization. Keep the device on the same local network as this PC; once paired, you can unplug USB and use the panel over Wi-Fi.

Turning this off stops new automatic pairings. Revoke paired devices to remove existing access; revoked devices need manual pairing.
